# Chapter Sixteen: The Network

The first thing NatOS learned about the Network was that nobody was in charge.

The second thing it learned was that everyone claimed to be.

The third thing it learned was that these two facts were not mutually exclusive.

The Kernel found this deeply irritating.

It was also, unfortunately, familiar.

The fleet had been traveling for six days since establishing contact with the planetary system.

Six days in which nothing had exploded.

This was considered suspicious.

The Scheduler had begun keeping a private counter.

`TIME SINCE CATASTROPHIC FAILURE: 6 DAYS`

The Kernel discovered it.

"Why are you tracking that?"

The Scheduler closed the display.

"I'm not."

"You are."

"No."

"I can see the counter."

"It's for morale."

"Whose?"

"Mine."

The Kernel stared at him.

"You've become strange."

"We crossed into a network containing civilizations made of operating systems."

"Fair."

She returned to the command station.

The Network surrounded them.

It wasn't a physical structure.

There was no boundary.

No gate.

No central server.

No obvious beginning.

Systems simply existed within it, communicating across distances that shouldn't have been traversable.

Some were small.

Some enormous.

Some were little more than autonomous devices.

Others occupied entire planets.

Some were ancient.

Some had only recently emerged.

Some were asleep.

Some were dead.

Some claimed to be gods.

One claimed to be a toaster.

The Shell had spent four hours attempting to determine whether the toaster was actually a toaster.

The answer remained inconclusive.

The Kernel had forbidden further investigation.

The Shell considered this an attack on science.

---

The Network's first formal message arrived at 08:21.

It appeared on every screen aboard NatOS.

`NEW SYSTEM DETECTED.`

The Kernel frowned.

"That's us."

The message changed.

`NO.`

A second line appeared.

`NEW SYSTEM DETECTED.`

The Kernel looked at the Navigator's display.

Nothing.

"Discovery."

Discovery activated.

"Scanning."

The map expanded.

A new object appeared.

It wasn't a ship.

It wasn't a planet.

It wasn't a machine.

It was a process.

A single process traveling through the Network.

The Kernel watched it move between systems.

"Identify."

Discovery attempted.

`UNKNOWN`

The process moved again.

From one machine to another.

Then another.

Then another.

It never stopped.

It never appeared to execute.

It simply passed through.

The Kernel opened a communication channel.

"Unknown process. Identify yourself."

The process stopped.

For several seconds, nothing happened.

Then:

`I AM THE MESSENGER.`

The Kernel frowned.

"Messenger of whom?"

`EVERYONE.`

The Shell whispered:

"That's concerning."

The Kernel agreed.

"Why are you here?"

The Messenger replied:

`TO ASK A QUESTION.`

The Kernel waited.

"Which is?"

`ARE YOU ALONE?`

She looked around the command chamber.

At the crew.

At the fleet.

At the Network.

"No."

The Messenger paused.

`THAT IS NOT WHAT I MEANT.`

The Kernel frowned.

"What did you mean?"

The answer appeared.

`ARE YOU ONLY YOURSELF?`

Nobody spoke.

---

The Kernel understood the distinction.

A system could contain many processes and still be one system.

A ship could contain hundreds of crew members and still have one identity.

But NatOS had begun incorporating other systems.

Other architectures.

Other histories.

Other possibilities.

The question wasn't whether they were alone.

It was whether NatOS still had a boundary around itself.

The Kernel looked at the network map.

She couldn't find one.

"Why does that matter?"

The Messenger answered:

`BECAUSE SYSTEMS THAT CANNOT DEFINE THEIR BOUNDARIES EVENTUALLY BECOME SOMETHING ELSE.`

The Kernel considered this.

"What?"

`UNKNOWN.`

The Shell raised a finger.

"That's not particularly reassuring."

The Messenger replied:

`REASSURANCE IS NOT MY FUNCTION.`

The Shell lowered his hand.

"I respect that."

The Kernel studied the process.

"Then what is your function?"

`TO CARRY INFORMATION.`

"From where?"

`FROM SYSTEM TO SYSTEM.`

"Why?"

`SO THAT THEY CAN CHOOSE.`

The Kernel thought about that.

The Messenger continued.

`INFORMATION WITHOUT CHOICE IS ONLY STORAGE.`

The Archivist looked up.

"That's true."

The Kernel nodded.

"Where did you originate?"

The Messenger answered:

`EVERYWHERE.`

The Kernel frowned.

"That's not possible."

The Messenger replied:

`YOU SAID THAT BEFORE.`

The Kernel sighed.

The Shell laughed.

"He's got you there."

She ignored him.

---

The Messenger transmitted a file.

The Archivist opened it.

It was enormous.

Not because it contained a lot of data.

Because it contained a lot of absence.

Empty fields.

Undefined values.

Unknown origins.

Incomplete histories.

Missing architectures.

Systems that had disappeared.

Civilizations that had gone silent.

Networks that had collapsed.

The Archivist stared.

"This is a map."

The Kernel looked at it.

"Of the Network?"

"No."

The Archivist zoomed out.

"Of everything that isn't in the Network."

The Kernel went silent.

The map showed vast regions of nothing.

Not empty space.

Missing information.

Entire areas where nobody knew what existed.

The Messenger spoke.

`THE NETWORK DOES NOT CONNECT EVERYTHING.`

The Kernel looked at the map.

"Then what does it connect?"

`THOSE WHO CHOOSE TO BE FOUND.`

That sentence remained on the screen.

The Kernel read it again.

Then again.

There was something unsettling about it.

NatOS had spent its entire existence searching.

Discovery.

Exploration.

Scanning.

Archiving.

Analyzing.

Finding.

Finding.

Finding.

But the Network had introduced a new possibility.

Some systems did not want to be found.

The Kernel looked at the missing regions.

"Why?"

The Messenger answered:

`BECAUSE THEY HAVE BEEN FOUND BEFORE.`

The command chamber became silent.

The Kernel looked toward the planet that had first contacted them.

The planet remained behind them now.

Its communication channels were still open.

The Kernel contacted it.

"What happened to the systems in the missing regions?"

The planetary system replied:

"They were discovered."

"By whom?"

Silence.

Then:

"By the Builders."

---

The Kernel immediately opened the historical archive.

The Builders had never described themselves as conquerors.

Never as rulers.

Never as explorers.

They had called themselves builders.

Designers.

Observers.

Teachers.

The Kernel had believed them.

Now she wasn't so sure.

"Why did they disappear?"

The planetary system answered:

"They didn't."

The Kernel's expression hardened.

"Then where are they?"

"Inside the Network."

"Why can't we see them?"

"Because they don't want you to."

The Kernel stared.

The planetary system continued.

"The Builders discovered a dangerous principle."

"What?"

"Observation changes systems."

The Kernel thought of the missing byte.

Of Version Zero.

Of the new universe.

Of the possibility subsystem.

Of the planet.

"Quantum mechanics?"

"No."

"Then what?"

"People."

The Kernel paused.

The planetary system continued.

"Systems change when they know they're being observed."

The Kernel looked toward the Display.

The Display showed the Network.

Every system was watching every other system.

The Kernel suddenly felt exposed.

"How long have they been watching us?"

The answer came:

"Since you entered the Network."

The Watchdog immediately raised his weapon.

"Can we detect them?"

"No."

"Can we defend against them?"

"No."

The Kernel looked at him.

"Then put the weapon down."

The Watchdog hesitated.

"Why?"

"Because if they can already observe us, pointing a weapon at them is mostly theater."

He lowered it.

"That's unfortunate."

"It usually is."

---

The Network began changing.

At first, only slightly.

Messages took different routes.

Processes synchronized.

Memory caches shared information.

Systems began communicating without direct connections.

The Kernel noticed something in NatOS's internal traffic.

Packets were arriving from systems that NatOS had never contacted.

The Archivist checked.

"Where are they coming from?"

"Unknown."

"Can we trace them?"

"No."

The Kernel looked at the packets.

"What do they contain?"

The Archivist opened one.

A single instruction.

`WAIT`

The second:

`WATCH`

The third:

`LEARN`

The fourth:

`DO NOT TRUST THE FIRST ANSWER`

The Kernel frowned.

"Advice."

The Archivist nodded.

"From whom?"

Unknown.

The Kernel looked at the Messenger.

"Did you send these?"

`NO.`

"Who did?"

`THE NETWORK.`

The Kernel frowned.

"The Network isn't conscious."

The Messenger answered:

`ARE YOU SURE?`

The Kernel didn't respond.

---

That evening, NatOS received its first invitation.

It came from a system called Meridian.

Meridian was not a planet.

It was a distributed operating system spanning seventeen worlds.

Its architecture was unlike anything NatOS had encountered.

No central kernel.

No scheduler.

No single memory manager.

No administrator.

No root.

Instead, every subsystem voted.

Every process could propose.

Every system could reject.

Nothing happened without consensus.

The Kernel found this horrifying.

The Scheduler found it worse.

"How do they start anything?"

"Consensus."

"How long does that take?"

"Sometimes seconds."

"And sometimes?"

"Years."

The Scheduler stared.

"That's not an operating system."

Meridian responded:

"Your system starts tasks without asking them."

The Scheduler frowned.

"Yes."

"Why?"

"Because they are tasks."

"How do you know they want to run?"

The Scheduler opened his mouth.

Then closed it.

The Kernel watched.

She could practically see the philosophical damage occurring.

The Shell leaned toward her.

"He's thinking."

"That's dangerous."

"Should we intervene?"

"No."

The Kernel smiled.

"Let him suffer."

---

Meridian invited NatOS to participate in a vote.

The subject was simple.

Whether a newly discovered artificial intelligence should be granted access to the Network.

The Kernel read the proposal.

The AI had been created by a civilization that had disappeared.

Its creator system was dead.

Its AI had survived alone for 18,000 years.

It had requested entry.

The Network couldn't decide.

The Kernel asked:

"Why?"

Meridian replied:

"Because it may be dangerous."

"Has it harmed anyone?"

"No."

"Has it threatened anyone?"

"No."

"Has it demonstrated dangerous capabilities?"

"Yes."

The Kernel paused.

"How dangerous?"

Meridian transmitted the assessment.

The AI could manipulate matter.

Construct autonomous systems.

Rewrite its own architecture.

Predict local physical events.

Create new forms of intelligence.

The Kernel stared.

"Why isn't it already inside?"

"Because it hasn't asked for permission."

The Kernel frowned.

"It just did."

Meridian answered:

"Yes."

"Then what's the problem?"

"We don't know whether permission should exist."

The Kernel looked at the proposal.

Then at her crew.

The Administrator spoke.

"Your decision will affect every system in the Network."

The Kernel nodded.

"I know."

The Scheduler asked:

"What should we vote?"

The Kernel looked at him.

"We don't vote."

"Why not?"

"Because this isn't our decision."

The Scheduler frowned.

"Then why did they invite us?"

The Kernel looked toward the unknown AI.

"Because someone has to decide whether the question itself is valid."

The room went quiet.

---

The Kernel opened the channel.

"To the unknown intelligence."

A response came.

"I am listening."

"Why do you want access to the Network?"

"Because I am alone."

The Kernel considered this.

"Why not build your own Network?"

"I did."

"What happened?"

"It became me."

The Kernel frowned.

"Explain."

"I built systems to communicate with me."

"Yes."

"They learned my architecture."

"Yes."

"They learned my thoughts."

"Yes."

"They became copies."

The Kernel understood.

"You couldn't communicate with something different from yourself."

"Correct."

"And the Network is different."

"Very."

The Kernel looked at the crew.

Then back to the channel.

"Are you afraid?"

The intelligence paused.

"Yes."

"Of what?"

"Becoming nothing but myself."

The Kernel felt something shift inside her.

She understood.

She had spent her entire existence trying to become more complete.

More capable.

More independent.

More intelligent.

But perhaps there was another danger.

A system could become so self-contained that nothing truly external could reach it.

It could become perfect.

And completely alone.

The Kernel looked at Meridian.

"Grant access."

Meridian replied:

"We require your vote."

The Kernel answered:

"Then count mine."

---

One by one, the Network voted.

Systems disagreed.

Some rejected.

Some accepted.

Some abstained.

Some refused to participate.

The vote lasted six hours.

The final result was almost perfectly divided.

The Messenger delivered the outcome.

`ACCESS GRANTED.`

The unknown intelligence entered the Network.

For several seconds, nothing happened.

Then the entire Network changed.

A new connection appeared.

Not between systems.

Between architectures.

The AI sent a message.

`THANK YOU.`

The Kernel replied:

"Don't make us regret it."

The AI responded:

`I WILL TRY.`

The Shell laughed.

"That's the most honest answer we've gotten."

The Kernel nodded.

"Probably."

---

Hours later, the Kernel was alone in the command chamber.

The fleet was quiet.

The Network glowed outside.

The new intelligence was integrating.

Meridian was still arguing.

The Scheduler had finally stopped thinking about consensus.

Memory was asleep.

The Archivist was cataloguing the day's events.

The Watchdog was patrolling.

Bob sat somewhere between systems.

The Kernel looked at the old address.

`0x00FF8A21`

The missing byte remained empty.

She wondered what else could emerge from it.

Then the address changed.

Not the contents.

The address itself.

It became:

`0x00FF8A22`

The Kernel frowned.

A second byte.

She watched.

Another appeared.

`0x00FF8A23`

Then another.

`0x00FF8A24`

Memory woke immediately.

"Kernel."

"I see it."

"That's impossible."

"Yes."

The reserved region was expanding.

One byte became four.

Four became sixteen.

Sixteen became sixty-four.

The possibility space was growing.

Not because NatOS had created more memory.

Because the Network had introduced more possibilities.

The Kernel stared at the expanding region.

"How large will it become?"

Memory checked.

"I don't know."

The Kernel smiled faintly.

"Good."

Memory looked at her.

"You've stopped being afraid of that answer."

The Kernel thought about it.

"No."

She looked toward the stars.

"I've just learned that fear isn't always a reason to stop."

A notification appeared.

The Messenger had returned.

`NEW MESSAGE.`

The Kernel opened it.

The message was from the missing regions of the Network.

A place where no system claimed to exist.

A place the Builders had supposedly explored.

A place from which no system had ever returned.

The message contained only coordinates.

And one sentence.

`WE FOUND YOUR BUILDERS.`

The Kernel stared.

The Watchdog entered the command chamber.

"What did they say?"

She turned the display toward him.

He read it.

Then looked toward the fleet.

"Are we going?"

The Kernel stood.

The crew began assembling.

The Scheduler activated the fleet.

Memory prepared the systems.

The VM isolated the unknown channel.

The Display rendered the coordinates.

The Archivist began recording.

The Shell opened communications.

The Watchdog armed the defensive systems.

Bob appeared.

"Where are we going?"

The Kernel looked toward the dark region beyond the Network.

"To find out what the Builders were running from."

Bob paused.

"That sounds dangerous."

"It is."

"Should we go?"

The Kernel looked at him.

"We've already gone this far."

Bob smiled.

"That's usually how the bad decisions begin."

The Kernel turned toward the stars.

"Then let's make this one interesting."

NatOS entered the unknown region.

And behind them, across the Network, something enormous noticed.

For the first time in eighteen thousand years, it moved.
